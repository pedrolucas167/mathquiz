# MathQuiz 📘🧮

A small educational math quiz game built with Java and Swing. Designed to reinforce basic arithmetic skills, including addition, subtraction, multiplication, and division.

## 🎯 Objective

Answer as many math questions as possible in the shortest amount of time. The remaining time directly influences your score — encouraging both speed and accuracy!

## 🧠 Features

- ✅ Random questions covering the four basic operations.
- ⏱️ 10-second timer for each question.
- 🎯 Scoring system with bonus based on remaining time.
- 🔄 Restart button to reset the game at any moment.
- 🧪 Input validation to ensure numeric answers.
- 🔢 Configurable number of questions per game (default: 10).

## 🛠️ Technologies Used

- Java 11+
- Java Swing (GUI)
- Object-Oriented Programming
